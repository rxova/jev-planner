# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/rxova/template-oss/security/advisories/new).

You will get an acknowledgement within a few days. Once a fix is released, the advisory is published
with credit to the reporter unless you ask otherwise.

## Supported versions

Only the latest published minor version receives security fixes.
